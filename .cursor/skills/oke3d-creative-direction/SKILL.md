# OKE3D Creative Direction

## Brand

OKE3D = Dutch 3D-printed figures / collectibles.

Feel: **collectible culture + 3D craft + digital art + premium product design**.

Not: SaaS, crypto, gaming, AI startup, corporate, kids toy store.

First impression must be: *"This is seriously well made."*

## Visual language

- Base: deep charcoal / near-black, off-white
- Accent: electric blue — **filament, edge light, type accent, micro UI** — never full background wash
- Blue is compositional, not decoration
- No default blue/purple gradient blobs

## Typography

Typography is a primary visual material.

- Large editorial display headlines
- Tight control of tracking, leading, measure
- Strong display vs body contrast
- Small uppercase metadata (`01 / OKE3D`)
- Short statements, not welcome copy

Concept tone (not locked copy):

- FIGURES MADE REAL.
- MADE TO EXIST.
- FROM DIGITAL TO PHYSICAL.
- BUILT TO BE HELD.

## Composition

Prefer: edge-to-edge, asymmetry, oversized type, overlapping layers, negative space, controlled crop, visual tension.

Avoid as default: `max-width:1200` centered everything, 3-column card grids, glassmorphism, identical border-radius everywhere.

## Product presentation

Products are collectible objects, not thumbnails.

Large imagery · generous space · subtle shadow · strong name · secondary price · small metadata.

## Hard anti-slop (forbidden default hero)

Black bg + blue gradient blob + big white headline + glowing CTA + floating object + fade-in-up everywhere + rounded cards + glass + random particles.

If a solution feels like a generic AI template → redesign.

## Decision rule

Between safe/generic and creative/distinctive → choose distinctive **only if** usability, performance, and a11y stay intact.

Premium = better timing, composition, type, imagery, whitespace, interaction, consistency — **not** more effects.
